模型训练 · 核心概念

梯度下降 GRADIENT DESCENT — how a model learns by going downhill

几乎所有神经网络的训练，本质上都是同一件事：在一个看不见全貌的"损失地形"上，一小步一小步地往低处走。这份教程让你亲手调一调，看清每一步到底发生了什么。

蒙眼下山

把数学先放一边。先建立一个能记一辈子的画面。

想象你被蒙住眼睛，站在一片连绵的山坡上，想走到最低的山谷。你看不见全貌，但每一步都能用脚感受到哪个方向最陡。

于是你的策略很简单：朝着脚下最陡的下坡方向，迈出一小步。然后重新感受、再迈一步，如此反复，直到脚下变平——你就到谷底了。

这就是梯度下降的全部直觉。下面这个小球，正在做的就是这件事。

⚠️ 一个关键细节：梯度指向损失上升最快的方向，所以下山时我们要朝它的反方向走——这就是公式里那个减号的由来。

一行更新公式

梯度下降的全部数学，浓缩在这一行里。每走一步，就执行一次它。鼠标悬停看每一块的含义。

θ := θ − α∇J(θ)
θ（参数 / theta）模型要学的全部权重。下山时就是你的"坐标"。训练就是不断更新它。
∇J(θ)（梯度 / nabla J）损失对每个参数的偏导，指向损失上升最快的方向。坡越陡，它越大。
α（学习率 / alpha）步长。太大就冲过头甚至发散，太小就慢得要命。整份教程里最值得你亲手调的旋钮。
−（减号）因为梯度指向上坡，要下山就得朝反方向走。整个"下降"二字就藏在这个负号里。

读成一句大白话

新位置 等于 旧位置， 减去 一小步（学习率） 乘以 当前最陡的上坡方向（梯度）。

坡越陡（梯度大）→ 这一步迈得越远；越接近谷底（梯度趋近 0）→ 步子自动变小，慢慢停下。这套"自动刹车"的机制，正是它优雅的地方。

四个经典陷阱

理论很美，但实战里梯度下降经常"翻车"。下面每张卡片配一个一键演示——点进去，在实验台里亲眼看它出问题。

α 太大

步子迈太大 → 震荡 / 发散

学习率过大时，每一步都冲过谷底落到对面更高处，越走越高，损失爆炸。这是新手最常见的"loss 变成 NaN"。

α 太小

步子太碎 → 慢得要命

学习率过小虽然稳，但要走成千上万步才到谷底，浪费大量算力和时间。调参就是在"快"和"稳"之间找平衡。

局部最小

掉进小坑 → 错过全局最优

地形崎岖时，小球会卡在离起点最近的小谷底，以为到家了，其实更深的谷在别处。换个起点结果可能完全不同。

病态条件

狭长山谷 → 来回横跳

当某些方向比其他方向陡得多，路径会沿谷壁反复"之"字形横跳，前进缓慢。这是用 Adam、动量等改进算法的核心动机。

那么，怎么办？

这些陷阱催生了梯度下降的一整个"家族"。了解原始版本的毛病，才能理解它们为什么存在：

动量 Momentum
→
累积历史方向，像滚下山的球，能冲过小坑、抑制横跳
AdaGrad / RMSProp
→
给每个参数自适应不同的学习率，缓解病态条件
Adam
→
动量 + 自适应学习率的结合，当今深度学习的默认选择
学习率调度
→
先大后小：开始快速下山，临近谷底时放慢精修
