# 《统计学入门很简单》公式手册

> 依据涌井良幸、涌井贞美《统计学入门很简单（图解版）》整理。
> 按章节列出全部数学公式，每条公式附书中示例（数字均来自原书案例）。
> 记号约定：x̄ 样本均值，μ 总体均值，σ² 总体方差，s² 无偏方差，n 样本容量。

## 第 1 章　数据的整理方法（描述统计）

### 1.1 频率与相对频率
| 公式 | 说明 |
|---|---|
| 相对频率 = 频率 ÷ 数据总数 | 相对频率与"概率"概念相通 |

**书中示例**：160 个零用钱数据分组后，组 25000~30000（组值 27500）频率 19，相对频率 19/160 = 0.11875。

### 1.2 平均值
```
x̄ = (x₁ + x₂ + … + xₙ) / n = 数据总和 / 数据总数
```
**书中示例**：三人身高 178、167、161 cm → (178+167+161)/3 = 168.7 cm。

### 1.3 中位数 / 众数
- **中位数**：数据从大到小排列后正中间的值；数据个数为偶数时取中间两数的平均。
- **众数**：出现次数最多的值（直方图峰顶）。

**书中示例**：178、175、170、169、165 → 中位数 170。
山型分布中三者接近；L 型分布中差别很大（家庭储蓄：众数最小 < 中位数 995 万 < 平均值 1680 万日元）。

### 1.4 偏差、波动、方差、标准差
```
偏差   = xᵢ − x̄            （全部偏差之和恒等于 0）
波动 Q = Σ(xᵢ − x̄)²         （偏差平方和）
方差 σ² = Q / n = Σ(xᵢ − x̄)² / n
标准差 σ = √方差             （单位与原数据一致）
```
**书中示例**：A 公司月薪 {30, 34, 32, 28, 26}（万日元），均值 30
→ 波动 = 0+16+4+4+16 = 40，方差 = 40/5 = 8。
对比：B 公司波动 136、方差 27.2；C 公司波动 1350、方差 270。方差越大 = 数据个性（信息量）越大。

### 1.5 协方差与相关系数
```
协方差   Sxy = Σ(xᵢ − x̄)(yᵢ − ȳ) / n
相关系数 r = Sxy / (Sx · Sy)      （−1 ≤ r ≤ 1）
```
判断标准（书中约定）：
| r 的范围 | 解释 |
|---|---|
| r ≤ −0.6 | 很强的负相关 |
| −0.6 < r ≤ −0.2 | 普通的负相关 |
| −0.2 < r < 0.2 | 不相关 |
| 0.2 ≤ r < 0.6 | 普通的正相关 |
| r ≥ 0.6 | 很强的正相关 |

**书中示例**：10 名员工身高体重，x̄=167、ȳ=61.5、Sx=7.87、Sy=9.29；
Sxy = [(169−167)(65−61.5) + (154−167)(50−61.5) + … ]/10 = 58
→ r = 58 / (7.87×9.29) = **0.79**（强正相关）。

### 1.6 交叉表格（列联表）
两个**定性变量**的关系用交叉表格可视化：行、列分别列出两个变量的取值，格内填同时满足两个条件的个体数。
**书中示例**：20 人的血型(A/AB/B/O)×性格(α/β/γ) 4×3 交叉表 → O 型 α 性格偏多。

## 第 2 章　概率 / 总体 / 样本

### 2.1 概率的定义
```
P(A) = r / n    （n：等可能结果总数；r：A 事件包含的结果数）
```
**书中示例**：硬币正面 1/2；骰子掷出 ≤2 的数字 = 2/6 = 1/3。

### 2.2 随机变量与概率分布
- 离散随机变量：用概率分布表表示，概率总和 = 1。
- 连续随机变量：用概率密度函数表示，曲线与横轴围成面积 = 1；取特定值的概率为 0，区间概率 = 面积。

**书中示例**：52 张扑克抽花色，P(X=1)=…=P(X=4)=13/52=0.25。

### 2.3 随机变量的平均值（期望）与方差
```
E(X) = x₁p₁ + x₂p₂ + … + xₙpₙ = Σ xᵢpᵢ
V(X) = Σ (xᵢ − m)² pᵢ ，其中 m = E(X)
```
连续型将区间无限分割后同理（积分思想）。

### 2.4 百分点与 p 值
- **上侧 100p 百分点**：分布图上右侧概率为 p 的点 x（下侧、两侧同理，两侧每边 p/2）。
- **p 值**：给定 x，其一侧（或两侧）的概率。

### 2.5 标准化
```
z = (x − m) / σ      → 均值 0、标准差 1
逆变换：x = σz + m
```

### 2.6 基本统计量
```
样本均值 X̄ = (X₁ + X₂ + … + Xₙ) / n                     …具有无偏性
样本方差 S² = Σ(Xᵢ − X̄)² / n                            …没有无偏性（平均偏小）
无偏方差 s² = Σ(Xᵢ − X̄)² / (n − 1)                      …具有无偏性
```
**自由度**：取值不受限的变量个数。因约束 Σ(Xᵢ−X̄)=0，n 个偏差的自由度为 **n−1**，这就是无偏方差分母取 n−1 的原因。

### 2.7 正态分布 N(μ, σ²)
- 曲线左右对称的山型；山顶横坐标 = μ；山腰（拐点）到 μ 的距离 = σ。
- μ=0、σ²=1 时称**标准正态分布 N(0,1)**。

**常用百分点（标准正态）**：
| 百分点 | 值 |
|---|---|
| 上侧 5% | 1.65 |
| 两侧 5% | 1.96 |
| 上侧 1% | 2.33 |
| 两侧 1% | 2.58 |

一般正态 N(μ,σ²) 的对应点：μ + 1.65σ、μ + 1.96σ、μ + 2.33σ、μ + 2.58σ。

### 2.8 中心极限定理
```
从均值 μ、方差 σ² 的任意总体抽取容量 n 的样本：
(1) X̄ 的平均值 = μ，方差 = σ²/n，标准差 = σ/√n
(2) n 足够大时（约 30 以上），无论总体是什么分布，X̄ 都近似正态分布
```

### 2.9 正态总体的样本均值定理
```
总体为 N(μ, σ²) 时，X̄ 严格服从 N(μ, σ²/n)   （任意 n 都成立）
```

## 第 3 章　估计 / 检验的基本思想

### 3.1 点估计与区间估计
**书中示例**：3 人零用钱 3、4、5 万日元 → 点估计 μ̂ = (3+4+5)/3 = 4 万日元。

### 3.2 区间估计原理（σ² 已知）
```
P( μ − 1.96·σ/√n ≤ X̄ ≤ μ + 1.96·σ/√n ) = 0.95
变形 → X̄ − 1.96·σ/√n ≤ μ ≤ X̄ + 1.96·σ/√n   （95% 置信区间）
99% 置信区间：把 1.96 换成 2.58
```
**书中示例**：σ²=1、n=3、X̄=4 → 4 ± 1.96/√3 → **2.87 ≤ μ ≤ 5.13**（95%）；99% 时 2.51 ≤ μ ≤ 5.49。

要点：
- 置信度 95% 的含义：所有可能的置信区间中，包含 μ 的区间占 95%（不能说 μ 在某个具体区间内的哪个位置）。
- 置信度提高 → 区间变宽；想在同置信度下缩窄区间，只能增大 n。

### 3.3 统计检验的思想
1. 设与想证明的主张相反的**原假设 H₀**（备择假设 H₁ 是想证明的）；
2. 假定 H₀ 成立，计算观测结果（或更极端结果）出现的概率；
3. 若该概率小于**显著性水平（风险率）α**（常用 0.05、0.01）→ 小概率事件发生 → **拒绝 H₀**，接受 H₁；否则不能拒绝 H₀。

**书中示例**：掷"合格骰子"10 次偶数出现 8 次，P(偶数≥8 次)=0.0547≈0.05 → α=5% 时拒绝"骰子合格"；α=1% 时不能拒绝（需 ≥9 次才是小概率，P≈0.01）。

### 3.4 单侧 / 双侧检验
| 备择假设 | 检验类型 | 拒绝域 |
|---|---|---|
| 参数 > λ | 右侧检验 | 分布右尾 |
| 参数 < λ | 左侧检验 | 分布左尾 |
| 参数 ≠ λ | 双侧检验 | 两尾各 α/2 |

### 3.5 两类错误
- **第一类错误（拒真）**：H₀ 正确却被拒绝；犯错率 = α（显著性水平）。
- **第二类错误**：H₀ 错误却没被拒绝；犯错率 β。
- α 与 β 此消彼长。

## 第 4 章　回归分析 / 方差分析 / 贝叶斯统计学

### 4.1 一元回归分析
```
回归方程 y = ax + b   （与所有点距离最小、即残差平方和最小的直线）
x：自变量，y：因变量
```
**书中示例**：广告费 x 与销售额 y（5 年数据）→ y = 5.575x + 39.779。

### 4.2 多元回归分析
```
y = ax + bu + c   （回归平面；自变量再多原理相同）
```
**书中示例**：加入员工数 u → y = 5.17x + 2.38u + 35.35。

### 4.3 决定系数（贡献率）
```
R² = 预计值的方差 / 测量值的方差
测量值的方差 = 预计值的方差 + 残差的方差
R² > 0.8 → 回归方程实际可用
```
**书中示例**：334 = 280.96885 + 53.00885 → R² = 280.96885/334 = **0.8412**。

### 4.4 自由度调整后的决定系数
```
R̄² = 1 − (n−1)(1−R²) / (n−k−1)     n：数据个数，k：自变量个数
```
**书中示例**：n=5、k=1、R²=0.8412 → R̄² = 1 − 4×0.1588/3 = 0.7883。
乱加无关自变量：k=2 时 R²=0.8465 但 R̄²=0.6930；k=3 时 R²=0.8547 但 R̄²=0.4188（R² 虚高、R̄² 反而下降）。

### 4.5 单因素方差分析（One-way ANOVA）
```
组间偏差 = 组平均值 − 总体均值        组间波动 Q₁ = 组间偏差平方和
组内偏差 = 原始数据 − 组平均值        组内波动 Q₂ = 组内偏差平方和
自由度   f₁ = 组数 − 1               f₂ = (组内区块数 − 1) × 组数
无偏方差 s₁² = Q₁/f₁                 s₂² = Q₂/f₂
检验统计量 F = s₁² / s₂²  ~  F(f₁, f₂)分布（H₀"无差异"成立时）
F 落入上侧拒绝域 → 拒绝 H₀（效果有差异）
分解式：原始数据 = 总体均值 + 组间偏差 + 组内偏差；总波动 Q = Q₁ + Q₂
```
**书中示例**：3 种肥料 × 4 区块，组平均 58/64/61，总均值 61
→ Q₁ = 4×[(−3)²+3²+0²] = 72，f₁=2，s₁²=36；Q₂=30，f₂=(4−1)×3=9，s₂²=30/9
→ F = 10.8 > F(2,9) 上侧 5% 点 4.26 → 拒绝"肥料无差异"。验证：Q=102=72+30。

### 4.6 双因素方差分析（无反复）
```
组内偏差(误差) = 原始数据 − 总体均值 − 因素1组间偏差 − 因素2组间偏差
f(因素) = 该因素水平数 − 1
f(误差) = (因素1水平数 − 1) × (因素2水平数 − 1)
各因素 F = 该因素无偏方差 / 组内(误差)无偏方差
```
**书中示例**：肥料 4 水平 × 湿度 3 水平，总均值 11.1、总波动 Q=98.8
→ 肥料 Q₁₁=64.9 (f=3)、湿度 Q₁₂=20.2 (f=2)、误差 Q₂=13.8 (f=3×2=6)。

### 4.7 双因素方差分析（有反复）
每格有多个数据时，可分离出**相互作用**：
```
相互作用偏差 = 原始数据 − 总体均值 − 因素1组间偏差 − 因素2组间偏差 − 组内偏差
f(相互作用) = (因素1水平数−1) × (因素2水平数−1)
f(组内) = (每格数据数 − 1) × 格数
```
**书中示例**：肥料 3 × 湿度 2 × 每格 4 个数据，Q=168.1；肥料 21.2、湿度 60.2、组内 46.9(f=18)、相互作用 39.8(f=2)。

### 4.8 概率的四个基本定理（贝叶斯的准备）
```
联合概率   P(A 且 B)
加法定理   P(A 或 B) = P(A) + P(B)          （A、B 互斥时）
条件概率   P(B|A)：A 已发生的条件下 B 发生的概率
乘法定理   P(A 且 B) = P(A) × P(B|A)
```
**书中示例**（52 张扑克）：P(红心且画像)=3/52；P(红心或梅花)=13/52+13/52；
P(画像|红心)=3/13；P(红心且画像)=13/52 × 3/13 = 3/52。

### 4.9 贝叶斯定理
```
P(H|D) = P(D|H) · P(H) / P(D)
P(H)：先验概率      P(H|D)：后验概率      P(D|H)：似然度
```
**书中示例**：两孩家庭，H="有女孩"（P=3/4）、D="有男孩"（P=3/4）、P(D|H)=2/3
→ P(H|D) = (2/3)×(3/4)/(3/4) = **2/3**。

## 第 5～6 章　应用篇（数据 / 概率 / 样本）

### 5.1 移动平均（时间序列）
```
三项移动平均：X'₂ = (X₁+X₂+X₃)/3，X'₃ = (X₂+X₃+X₄)/3，…
```
作用：平滑剧烈波动，显现长期趋势。

### 5.2 异常值
用相关图肉眼识别明显偏离主体的点，判断成因后剔除再分析。
**书中示例**：10 名学生成绩中 8 号（英语 90、数学 5，看不懂日语试卷的留学生）为异常值；剔除后数学平均 54.4 > 英语 50.9，结论反转。

### 5.3 期望值
```
期望值 = Σ(各金额 × 其概率) = 奖金总额 / 奖券总数
```
**书中示例**：100 张奖券（2 张 1000 日元 + 10 张 100 日元 + 88 张 0）
→ E = (1000×2 + 100×10)/100 = 30 日元 < 每次 50 日元 → 每次期望亏 20 日元。

### 5.4 蒙特卡罗法求 π
```
边长 2m 正方形内切半径 1m 圆。随机撒点：正方形内 m 粒、圆内 n 粒
4 : π ≈ m : n   →   π ≈ 4n/m
```
**书中示例**：Excel 随机 100 点 → π≈3.04；1000 点 → π≈3.13。

### 5.5 大数定律
试验次数增加时，事件的相对频率逐渐稳定并趋近其真实概率（初期会"摇摆不定"）。

### 5.6 总体比例的区间估计（调查问卷样本量）
```
95% 置信区间：r − e ≤ R ≤ r + e，其中 e = 2√( r(1−r)/n )
（严格应为 1.96，书中取整为 2；注意原书表格标题误印作 r(r−1)，应为 r(1−r)）
```
要点：r=0.5 时 e 最大；n=400 时 e≈0.05 已够用，n=1000 万无一失；**所需样本量与总体规模无关**。

## 第 7 章　估计 / 检验的应用（公式速查）

### 7.1 极大似然估计
似然函数 = 各次试验结果概率之乘积；使似然函数最大的参数值即估计值。
**书中示例**：图钉掷 5 次"上上下上下"→ y = p³(1−p)²，p=0.6 时最大 → p̂ = 3/5。

### 7.2 总体均值的区间估计（三种情形）
| 情形 | 统计量 / 分布 | 95% 置信区间 |
|---|---|---|
| 大样本 n≥30，总体分布未知（σ≈s） | 中心极限定理 | X̄ ± 1.96·s/√n |
| 小样本 n<30，正态总体，σ 未知 | T=(X̄−μ)/(s/√n) ~ t(n−1) | X̄ ± t(n−1) 两侧5%点 · s/√n |
| 正态总体，σ 已知 | X̄ ~ N(μ, σ²/n) | X̄ ± 1.96·σ/√n |

**书中示例**：
- 大样本：n=50、X̄=15900、s=1680 → 15400 ≤ μ ≤ 16400
- 小样本：n=20、X̄=15900、s=1710，df=19 的 t 两侧 5% 点 2.09 → 15100 ≤ μ ≤ 16700
- σ 已知：n=16、X̄=15900、σ=2000 → 14900 ≤ μ ≤ 16900

### 7.3 总体比例的区间估计
```
样本比例 r ~ N( R, R(1−R)/n )   （0-1 量化：μ=R，σ²=R(1−R)）
95% 置信区间：r ± 1.96·√( r(1−r)/n )      （99% 用 2.58）
```
**书中示例**：单身率 n=100、r=0.48 → 0.38 ≤ R ≤ 0.58；
内阁支持率 n=1034、r=0.52 → 0.48 ≤ R ≤ 0.55（95%）、0.47 ≤ R ≤ 0.56（99%）。

### 7.4 总体方差的区间估计（χ² 分布）
```
K = (n−1)s²/σ² ~ χ²(n−1)
95% 置信区间：(n−1)s²/χ²上限 ≤ σ² ≤ (n−1)s²/χ²下限
```
**书中示例**：n=20、s²=2910000；df=19 的 χ² 两侧 5% 点 [8.91, 32.85]
→ 1680000 ≤ σ² ≤ 6210000 → 1300 ≤ σ ≤ 2490。

### 7.5 各类检验一览
| 检验对象 | 统计量 | 分布 | 书中示例 |
|---|---|---|---|
| 总体比例 | r 直接比较，r ~ N(R, R(1−R)/n) | 正态 | 吸烟率：H₀ R=0.324，上侧5%点0.40，实测 r=0.42 → 拒绝 |
| 总体均值（σ 已知/大样本） | X̄ ~ N(μ₀, σ²/n) | 正态 | 数学成绩：上侧5%点65.0，X̄=63.2 → 不拒绝；新生儿体重：下侧5%点2.94，X̄=2.91 → 拒绝 |
| 总体均值（小样本） | T = (X̄−μ₀)/(s/√n) | t(n−1) | 睡眠时间：T=−0.81，df=9 两侧1%点±3.25 → 不拒绝 |
| 两总体均值差（方差同、未知） | T = (X̄A−X̄B) / √[ (1/nA+1/nB)·((nA−1)sA²+(nB−1)sB²)/(nA+nB−2) ] | t(nA+nB−2) | 东京vs大阪零用钱：T=0.70，df=18 两侧1%点2.88 → 不拒绝 |
| 两总体比例差 | z = (p₁−p₂)/√[ p(1−p)(1/n₁+1/n₂) ]，p=(n₁p₁+n₂p₂)/(n₁+n₂) | N(0,1) | 击球率：z=0.369 < 1.96 → 不拒绝 |
| 总体方差 | χ² = (n−1)s²/σ₀² | χ²(n−1) | 葡萄酒容量：χ²=14.6 ∈ [2.70,19.02] → 不拒绝 |
| 两总体方差比 | f = sA²/sB² | F(nA−1, nB−1) | 装袋作业：f=2.08 ≥ 1.85 → 拒绝（方差不等） |
| 拟合优度 | χ² = Σ(观测fᵢ−期望eᵢ)²/eᵢ | χ²(类别数−1) | 骰子300次：χ²=2.88 < 11.07(df=5) → 不拒绝 |
| 独立性（列联表） | 同上，期望频率 = 行合计×列合计/总数 | χ²((行−1)×(列−1)) | 料理喜好2×2：χ²=19.23 > 3.84(df=1) → 拒绝（喜好不同） |

### 7.6 二项概率（奶茶女士实验）
```
n 次中恰好 r 次的概率 = C(n,r) pʳ (1−p)ⁿ⁻ʳ
```
**书中示例**：随口猜 10 杯中对 8 杯的概率 C(10,8)(1/2)¹⁰ = 45/1024 ≈ 0.0439；P(≥8 次) ≈ 0.05 → 能拒绝"靠猜"。

## 第 8 章　应用案例中的补充公式

### 8.1 标准回归系数
单位不同的自变量不能直接比较回归系数大小；先把数据标准化再回归，得到**标准回归系数**。
**书中示例**：y=2.14x−0.13u+84.80 标准化后 → y=0.98x−0.007u（可见 u 的影响接近 0）。

### 8.2 贝叶斯应用四例
1. **口袋白球**（不充分理由原则）：4 种组合先验各 1/4，取出 1 白球后，后验 P(3白|白) = 3/10（后验依次 1/10, 2/10, 3/10, 4/10）。
2. **体检阳性**：P(患病)=0.02，P(阳|病)=0.95，P(阳|无病)=0.06
   → P(阳)=0.02×0.95+0.98×0.06=0.0778 → P(病|阳)=0.019/0.0778≈**0.224**。
   分母展开：P(D) = P(A)P(D|A) + P(非A)P(D|非A)（加法+乘法定理）。
3. **蒙提霍尔问题**：打开 C 后 P(A|开C)=1/3、P(B|开C)=2/3 → 应该换。
4. **贝叶斯更新**（硬币正面概率 θ）：先验均匀 P(θ)=1
   → 第 1 次正面后 P(θ|正)=2θ → 第 2 次正面后 3θ² → 第 3 次反面后 12θ²(1−θ)（峰值 θ=2/3，与"3 次中 2 次正面"的经验一致）。数据顺序不影响最终结果（顺序合理性）。

### 8.3 朴素贝叶斯垃圾邮件过滤
```
P(H₁|D) ∝ P(D|H₁)·P(H₁)，关键词相互独立时 P(D|H₁) = ΠP(Dᵢ|H₁)
比较 P(H₁|D) 与 P(H₂|D)，大者胜出
```
**书中示例**：垃圾:普通=7:3；检测到"立刻、免费、经济"
→ P(H₁|D)=k×0.6×0.7×0.1×0.7=0.0294k > P(H₂|D)=k×0.3×0.2×0.6×0.3=0.0108k → 判为垃圾邮件。

### 8.4 天气预报
先验 P(晴)=0.3、P(阴)=0.6、P(雨)=0.1；似然 P(明雨|·)=0.2 / 0.5 / 0.4
→ P(D)=0.06+0.30+0.04=0.4 → P(阴|明雨)=0.5×0.6/0.4=**0.75**。
