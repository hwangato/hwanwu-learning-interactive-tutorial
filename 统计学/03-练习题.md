## 一、数据的整理（第 1 章）

### 第 1 题 ★ 平均值、中位数、众数
某小组 5 人的英语成绩为：62、70、58、70、65。求平均值、中位数、众数。

**【答案】** 平均值 65，中位数 65，众数 70。

**【解题步骤】**
1. 平均值 = (62+70+58+70+65)/5 = 325/5 = **65**。
2. 排序：58、62、65、70、70，共 5 个（奇数），正中间第 3 个 = **65**。
3. 出现次数最多的是 70（2 次）→ 众数 = **70**。

### 第 2 题 ★ 波动、方差、标准差
数据：4、8、6、2、10。求波动（偏差平方和）、方差、标准差。

**【答案】** 波动 40，方差 8，标准差 2√2 ≈ 2.83。

**【解题步骤】**
1. 平均值 = (4+8+6+2+10)/5 = 6。
2. 偏差：−2、2、0、−4、4（检查：和为 0 ✓）。
3. 波动 Q = 4+4+0+16+16 = **40**。
4. 方差 = Q/n = 40/5 = **8**；标准差 = √8 ≈ **2.83**。

### 第 3 题 ★★ 协方差与相关系数
5 名学生的学习时间 x（小时）与得分 y：
x = {1, 2, 3, 4, 5}，y = {2, 3, 5, 4, 6}。求协方差 Sxy 和相关系数 r，并按书中标准判断相关程度。

**【答案】** Sxy = 1.8，r = 0.9，很强的正相关。

**【解题步骤】**
1. x̄ = 3，ȳ = 4。
2. 偏差乘积：(−2)(−2)+(−1)(−1)+(0)(1)+(1)(0)+(2)(2) = 4+1+0+0+4 = 9。
3. 协方差 Sxy = 9/5 = **1.8**。
4. Sx² = (4+1+0+1+4)/5 = 2 → Sx = √2；同理 Sy² = (4+1+1+0+4)/5 = 2 → Sy = √2。
5. r = Sxy/(Sx·Sy) = 1.8/2 = **0.9** ≥ 0.6 → **很强的正相关**。

### 第 4 题 ★ 标准化
某次考试成绩服从均值 60、标准差 8 的分布。小明得 74 分，求标准化后的 z 值。
（延伸：若定义"偏差值 = 50 + 10z"，小明的偏差值是多少？）

**【答案】** z = 1.75；偏差值 67.5。

**【解题步骤】**
1. z = (x−m)/σ = (74−60)/8 = 14/8 = **1.75**。
2. 偏差值 = 50 + 10×1.75 = **67.5**。

## 二、概率与随机变量（第 2 章）

### 第 5 题 ★ 随机变量的期望与方差
随机变量 X 的分布：P(X=0)=1/4，P(X=1)=1/2，P(X=2)=1/4。求 E(X) 和 V(X)。

**【答案】** E(X) = 1，V(X) = 0.5。

**【解题步骤】**
1. E(X) = 0×1/4 + 1×1/2 + 2×1/4 = **1**。
2. V(X) = (0−1)²×1/4 + (1−1)²×1/2 + (2−1)²×1/4 = 1/4 + 0 + 1/4 = **0.5**。

### 第 6 题 ★ 样本方差与无偏方差
样本：5、7、9。分别求样本方差 S²（分母 n）和无偏方差 s²（分母 n−1），并说明哪个用于推断总体方差。

**【答案】** S² = 8/3 ≈ 2.67；s² = 4；推断总体用无偏方差。

**【解题步骤】**
1. X̄ = (5+7+9)/3 = 7；波动 = 4+0+4 = 8。
2. 样本方差 S² = 8/3 ≈ **2.67**；无偏方差 s² = 8/(3−1) = **4**。
3. 样本方差的平均值系统性小于总体方差（有偏），无偏方差的平均值等于总体方差，因此推断总体方差用 **s²**。分母 n−1 源于约束 Σ(Xᵢ−X̄)=0 使自由度为 n−1。

### 第 7 题 ★★ 中心极限定理
某总体均值 μ=170、标准差 σ=6（分布形状未知）。抽取 n=36 的样本，问：
(1) 样本均值 X̄ 近似服从什么分布？
(2) X̄ 以 95% 的概率落在哪个区间？

**【答案】** (1) N(170, 1)；(2) [168.04, 171.96]。

**【解题步骤】**
1. 由中心极限定理，n=36 足够大：X̄ 的均值 = μ = 170，标准差 = σ/√n = 6/√36 = 1 → X̄ ≈ **N(170, 1²)**。
2. 95% 区间 = μ ± 1.96×(σ/√n) = 170 ± 1.96×1 = **[168.04, 171.96]**。

## 三、区间估计（第 3、7 章）

### 第 8 题 ★★ 总体均值区间估计（σ 已知）
正态总体 σ=10。抽取 n=25，得 X̄=200。求总体均值 μ 的 95% 和 99% 置信区间。

**【答案】** 95%：[196.08, 203.92]；99%：[194.84, 205.16]。

**【解题步骤】**
1. σ/√n = 10/5 = 2。
2. 95%：200 ± 1.96×2 = 200 ± 3.92 → **196.08 ≤ μ ≤ 203.92**。
3. 99%：200 ± 2.58×2 = 200 ± 5.16 → **194.84 ≤ μ ≤ 205.16**。
4. 对比可见：置信度提高，区间变宽（打靶时"扩大靶子才容易命中"）。

### 第 9 题 ★★ 总体均值区间估计（大样本）
随机调查 100 名上班族的午餐费，得 X̄=1500 日元、无偏方差算得标准差 s=200 日元。总体分布未知。求总体均值的 95% 置信区间。

**【答案】** [1460.8, 1539.2]（约 1461~1539 日元）。

**【解题步骤】**
1. n=100 ≥ 30 为大样本 → 用中心极限定理，且 σ 可用 s 近似。
2. s/√n = 200/10 = 20。
3. 1500 ± 1.96×20 = 1500 ± 39.2 → **1460.8 ≤ μ ≤ 1539.2**。

### 第 10 题 ★★ 总体均值区间估计（小样本，t 分布）
正态总体，抽取 n=16，得 X̄=50、s=8。已知自由度 15 的 t 分布两侧 5% 点为 2.131。求 μ 的 95% 置信区间。

**【答案】** [45.74, 54.26]。

**【解题步骤】**
1. n=16 < 30 且 σ 未知 → 用 T=(X̄−μ)/(s/√n) ~ t(n−1)=t(15)。
2. s/√n = 8/4 = 2。
3. 50 ± 2.131×2 = 50 ± 4.26 → **45.74 ≤ μ ≤ 54.26**。
4. 注意：t 临界值 2.131 > 1.96，小样本的区间比大样本更宽（不确定性更大）。

### 第 11 题 ★★ 总体比例区间估计
调查 400 人，240 人支持某政策（样本比例 r=0.6）。求总体支持率 R 的 95% 置信区间。

**【答案】** [0.552, 0.648]，即约 55.2%~64.8%。

**【解题步骤】**
1. 样本比例 r ~ N(R, R(1−R)/n)，用 r 近似 R 计算标准差：
   √(r(1−r)/n) = √(0.6×0.4/400) = √0.0006 ≈ 0.0245。
2. 0.6 ± 1.96×0.0245 = 0.6 ± 0.048 → **0.552 ≤ R ≤ 0.648**。

### 第 12 题 ★ 问卷调查的误差幅度
用书中简化公式 e = 2√(r(1−r)/n)，计算 n=1000、r=0.5 时的误差 e。调查报告说"支持率 50%"，应如何解读？

**【答案】** e ≈ 0.032；95% 置信下真实支持率约在 46.8%~53.2% 之间。

**【解题步骤】**
1. e = 2√(0.5×0.5/1000) = 2√0.00025 = 2×0.0158 ≈ **0.032**。
2. R ∈ 0.5 ± 0.032 → **[0.468, 0.532]**（置信度 95%）。
3. r=0.5 是误差最大的情形；样本量与总体规模无关，n=1000 时误差已约 ±3%。

### 第 13 题 ★★★ 总体方差区间估计（χ² 分布）
正态总体，抽取 n=10，算得无偏方差 s²=16。已知自由度 9 的 χ² 分布两侧 5% 点为 [2.70, 19.02]。求 σ² 和 σ 的 95% 置信区间。

**【答案】** 7.57 ≤ σ² ≤ 53.33；2.75 ≤ σ ≤ 7.30。

**【解题步骤】**
1. K = (n−1)s²/σ² ~ χ²(9)；95% 概率下 2.70 ≤ K ≤ 19.02。
2. (n−1)s² = 9×16 = 144。
3. 变形为 σ² 的不等式：144/19.02 ≤ σ² ≤ 144/2.70 → **7.57 ≤ σ² ≤ 53.33**。
4. 开平方：**2.75 ≤ σ ≤ 7.30**。
5. 注意 χ² 分布不对称，区间上下限不是围绕 s²=16 对称的。

## 四、假设检验（第 3、7 章）

### 第 14 题 ★★ 总体均值检验（σ 已知，双侧）
某零件规格重量 500g，已知 σ=20g。抽 n=25 件，X̄=510g。显著性水平 5%，检验重量是否偏离规格。

**【答案】** 拒绝原假设：重量与规格有显著差异。

**【解题步骤】**
1. H₀: μ=500；H₁: μ≠500（双侧检验）。
2. H₀ 下 X̄ ~ N(500, 20²/25)，标准差 = 20/5 = 4。
3. z = (510−500)/4 = 2.5。
4. |2.5| > 1.96（两侧 5% 点）→ 落入拒绝域 → **拒绝 H₀**，认为重量偏离规格。

### 第 15 题 ★★ 总体均值检验（小样本 t 检验）
某产品填充量标称 7.0ml。抽 n=9，得 X̄=7.4、s=0.6。自由度 8 的 t 两侧 5% 点为 2.306。α=5%，检验填充量是否与标称不同。

**【答案】** 不能拒绝原假设：不能认为填充量与 7.0 不同。

**【解题步骤】**
1. H₀: μ=7.0；H₁: μ≠7.0。
2. T = (7.4−7.0)/(0.6/√9) = 0.4/0.2 = 2.0。
3. |2.0| < 2.306 → 不在拒绝域 → **不能拒绝 H₀**。
4. 注意结论表述："没有充分证据说明不同"，而不是"证明了相同"。

### 第 16 题 ★★ 总体比例检验（单侧）
去年某市支持率为 30%。今年抽 100 人，38 人支持（r=0.38）。α=5%，检验支持率是否上升。

**【答案】** 拒绝原假设：可以认为支持率上升了。

**【解题步骤】**
1. H₀: R=0.30；H₁: R>0.30（右侧检验）。
2. H₀ 下 r ~ N(0.30, 0.30×0.70/100)，标准差 = √0.0021 ≈ 0.0458。
3. 上侧 5% 点 = 0.30 + 1.65×0.0458 ≈ 0.376。
4. r = 0.38 > 0.376 → 落入拒绝域 → **拒绝 H₀**，支持率上升。
   （若把 α 收紧到 1%：临界点 = 0.30+2.33×0.0458 ≈ 0.407，则不能拒绝——显著性水平的选择会影响结论。）

### 第 17 题 ★★★ 两总体均值差检验（t 检验）
两班考试成绩（正态总体、方差相同但未知）：
A 班 nA=6、X̄A=82、sA²=25；B 班 nB=6、X̄B=74、sB²=30。
自由度 10 的 t 两侧 5% 点为 2.228。α=5%，检验两班平均分是否有差异。

**【答案】** T ≈ 2.64 > 2.228，拒绝原假设：两班有显著差异。

**【解题步骤】**
1. H₀: μA=μB；H₁: μA≠μB。
2. 合并方差 = ((nA−1)sA² + (nB−1)sB²)/(nA+nB−2) = (5×25+5×30)/10 = 27.5。
3. 标准误 = √[(1/6+1/6)×27.5] = √(27.5/3) ≈ 3.028。
4. T = (82−74)/3.028 ≈ **2.64**。
5. 2.64 > 2.228 → **拒绝 H₀**，两班平均分有差异。

### 第 18 题 ★★★ 两总体比例差检验
产品 A：n₁=200 人中 70 人满意（p₁=0.35）；产品 B：n₂=300 人中 81 人满意（p₂=0.27）。α=5%（双侧），检验满意率是否有差异。

**【答案】** z ≈ 1.91 < 1.96，不能拒绝：无显著差异。

**【解题步骤】**
1. H₀: R₁=R₂；H₁: R₁≠R₂。
2. 合并比例 p = (70+81)/(200+300) = 151/500 = 0.302。
3. 标准误 = √[p(1−p)(1/n₁+1/n₂)] = √[0.302×0.698×(1/200+1/300)] = √0.001757 ≈ 0.0419。
4. z = (0.35−0.27)/0.0419 ≈ **1.91**。
5. |1.91| < 1.96 → **不能拒绝 H₀**（很接近临界值，可考虑增大样本再验证）。

### 第 19 题 ★★ 总体方差检验（χ² 检验）
机器灌装方差历来为 σ²=4。抽 n=16，得 s²=7。自由度 15 的 χ² 两侧 5% 点为 [6.26, 27.49]。α=5%，检验方差是否发生变化。

**【答案】** χ² = 26.25 ∈ [6.26, 27.49]，不能拒绝：不能认为方差变了。

**【解题步骤】**
1. H₀: σ²=4；H₁: σ²≠4。
2. χ² = (n−1)s²/σ₀² = 15×7/4 = **26.25**。
3. 26.25 在接受域 [6.26, 27.49] 内 → **不能拒绝 H₀**。

### 第 20 题 ★★ 两总体方差比检验（F 检验）
甲的包装重量无偏方差 sA²=9（nA=21），乙的 sB²=4（nB=16）。F(20,15) 两侧 5% 拒绝域为 f≥2.76 或 f≤0.36。α=5%，检验两人方差是否不同。

**【答案】** f = 2.25，不在拒绝域，不能拒绝：不能认为方差不同。

**【解题步骤】**
1. H₀: σA²=σB²；H₁: σA²≠σB²。
2. f = sA²/sB² = 9/4 = **2.25**，服从 F(nA−1, nB−1) = F(20,15)。
3. 0.36 < 2.25 < 2.76 → 在接受域内 → **不能拒绝 H₀**。

### 第 21 题 ★★ 拟合优度检验
掷硬币 100 次：正面 62 次、反面 38 次。χ²(1) 上侧 5% 点为 3.84。α=5%，检验硬币是否均匀。

**【答案】** χ² = 5.76 > 3.84，拒绝：硬币不均匀。

**【解题步骤】**
1. H₀: 正反面概率相同（期望各 50 次）；H₁: 不同。
2. χ² = (62−50)²/50 + (38−50)²/50 = 144/50 + 144/50 = **5.76**。
3. 自由度 = 类别数−1 = 1；5.76 > 3.84 → **拒绝 H₀**。

### 第 22 题 ★★★ 独立性检验（2×2 列联表）
调查 200 人对某产品的喜好：

| | 喜欢 | 不喜欢 | 合计 |
|---|---|---|---|
| 男 | 78 | 42 | 120 |
| 女 | 42 | 38 | 80 |
| 合计 | 120 | 80 | 200 |

χ²(1) 上侧 5% 点 3.84。α=5%，检验性别与喜好是否相关。

**【答案】** χ² = 3.125 < 3.84，不能拒绝：不能认为喜好与性别有关。

**【解题步骤】**
1. H₀: 喜好与性别无关；H₁: 有关。
2. 期望频率 = 行合计×列合计/总数：
   男喜欢 120×120/200=72；男不喜欢 120×80/200=48；女喜欢 80×120/200=48；女不喜欢 80×80/200=32。
3. χ² = (78−72)²/72 + (42−48)²/48 + (42−48)²/48 + (38−32)²/32
   = 0.5 + 0.75 + 0.75 + 1.125 = **3.125**。
4. 自由度 = (2−1)×(2−1) = 1；3.125 < 3.84 → **不能拒绝 H₀**。

## 五、方差分析与回归（第 4、8 章）

### 第 23 题 ★★★ 单因素方差分析
三种教学方法各教 3 名学生，成绩如下：

| | 方法A | 方法B | 方法C |
|---|---|---|---|
| 学生1 | 9 | 13 | 11 |
| 学生2 | 10 | 14 | 12 |
| 学生3 | 11 | 15 | 13 |

F(2,6) 上侧 5% 点为 5.14。α=5%，检验教学方法是否有差异。

**【答案】** F = 12 > 5.14，拒绝：教学方法效果有差异。

**【解题步骤】**
1. H₀: 方法无差异；H₁: 有差异。
2. 组平均：A=10、B=14、C=12；总体均值 = 12。
3. 组间偏差 = 组平均−总均值 = −2、+2、0；
   组间波动 Q₁ = 3×[(−2)²+2²+0²] = 24；f₁ = 3−1 = 2；s₁² = 24/2 = 12。
4. 组内偏差 = 原始数据−组平均，每组都是 −1、0、1；
   组内波动 Q₂ = (1+0+1)×3 = 6；f₂ = (3−1)×3 = 6；s₂² = 6/6 = 1。
5. F = s₁²/s₂² = 12/1 = **12** > 5.14 → **拒绝 H₀**。
6. 验证分解：总波动 Q = 14+14+2 = 30 = Q₁+Q₂ = 24+6 ✓。

### 第 24 题 ★★★ 一元回归与决定系数
数据：(x, y) = (1, 3)、(2, 4)、(3, 8)。
(1) 求回归方程 y = ax + b（提示：a = Sxy/Sx²，b = ȳ − a·x̄）；
(2) 求决定系数 R²，判断回归方程是否实用。

**【答案】** y = 2.5x；R² ≈ 0.893 > 0.8，实用。

**【解题步骤】**
1. x̄=2、ȳ=5。Sxy = [(−1)(−2)+(0)(−1)+(1)(3)]/3 = 5/3；Sx² = (1+0+1)/3 = 2/3。
2. a = (5/3)/(2/3) = 2.5；b = 5 − 2.5×2 = 0 → **y = 2.5x**。
3. 预计值：2.5、5、7.5；残差：0.5、−1、0.5。
4. 测量值方差 = [(3−5)²+(4−5)²+(8−5)²]/3 = 14/3 ≈ 4.667；
   预计值方差 = [(2.5−5)²+0+(7.5−5)²]/3 = 12.5/3 ≈ 4.167；
   残差方差 = (0.25+1+0.25)/3 = 0.5。（验证：4.167+0.5 = 4.667 ✓）
5. R² = 预计值方差/测量值方差 = 4.167/4.667 ≈ **0.893** > 0.8 → 实用。

### 第 25 题 ★★ 自由度调整后的决定系数
某一元回归（n=5、k=1）的 R²=0.85。求 R̄²。若增加 1 个无关自变量后 R² 升到 0.87（k=2），R̄² 变为多少？说明了什么？

**【答案】** k=1 时 R̄²=0.80；k=2 时 R̄²≈0.74。R² 虚增而 R̄² 下降，说明新变量没有价值。

**【解题步骤】**
1. R̄² = 1 − (n−1)(1−R²)/(n−k−1)。
2. k=1：R̄² = 1 − 4×0.15/3 = 1 − 0.20 = **0.80**。
3. k=2：R̄² = 1 − 4×0.13/2 = 1 − 0.26 = **0.74**。
4. 添加无关变量使 R² 从 0.85→0.87"变好"，但 R̄² 从 0.80→0.74 变差 → 评价多元回归应同时看 R̄²。

## 六、期望值、模拟与贝叶斯（第 6、8 章）

### 第 26 题 ★ 期望值
某抽奖共 200 张券：1 张中 5000 日元，9 张中 500 日元，其余 190 张无奖。每张售价 100 日元。求每张券的期望奖金，并判断是否值得购买。

**【答案】** 期望 47.5 日元 < 100 日元，每张期望亏 52.5 日元，不值得。

**【解题步骤】**
1. 期望值 = 奖金总额/奖券总数 = (5000×1 + 500×9 + 0×190)/200 = 9500/200 = **47.5 日元**。
2. 等价算法：Σ(金额×概率) = 5000×(1/200) + 500×(9/200) = 25 + 22.5 = 47.5 ✓。
3. 47.5 − 100 = −52.5 → 每张期望亏损 52.5 日元。

### 第 27 题 ★ 蒙特卡罗法
在边长 2m 的正方形（内切半径 1m 的圆）内随机撒 400 粒米，数得圆内有 314 粒。估计 π。

**【答案】** π ≈ 3.14。

**【解题步骤】**
1. 正方形面积:圆面积 = 4:π ≈ m:n = 400:314。
2. π ≈ 4n/m = 4×314/400 = **3.14**。

### 第 28 题 ★★ 极大似然估计
掷一枚图钉 4 次，结果为"上、上、上、下"。用极大似然法估计针朝上的概率 p。

**【答案】** p̂ = 3/4。

**【解题步骤】**
1. 似然函数 y = p×p×p×(1−p) = p³(1−p)。
2. 求最大：y' = 3p²−4p³ = p²(3−4p) = 0 → p = 3/4（不会微分也可代入 p=0.1,0.2,…,0.9 列表比较，p=0.75 附近 y 最大）。
3. p̂ = **3/4**，恰好等于"4 次中 3 次朝上"的直观频率。

### 第 29 题 ★★★ 贝叶斯定理（体检问题）
某疾病患病率 1%。检查的灵敏度为 90%（患病者阳性概率），未患病者也有 5% 概率误报阳性。某人检查呈阳性，求其真正患病的概率。

**【答案】** 约 15.4%。

**【解题步骤】**
1. 设 A=患病、D=阳性。P(A)=0.01、P(D|A)=0.90、P(D|非A)=0.05。
2. 分母用加法+乘法定理拆分：
   P(D) = P(A)P(D|A) + P(非A)P(D|非A) = 0.01×0.90 + 0.99×0.05 = 0.009 + 0.0495 = 0.0585。
3. 贝叶斯定理：P(A|D) = P(D|A)P(A)/P(D) = 0.009/0.0585 ≈ **0.154**。
4. 直观验证（设 10000 人）：患病 100 人中阳性 90 人；健康 9900 人中误报 495 人；真患病比例 = 90/(90+495) ≈ 15.4% ✓。阳性≠大概率患病，因为患病率本身很低。

### 第 30 题 ★★★ 朴素贝叶斯垃圾邮件判断
已知垃圾邮件与普通邮件之比为 6:4。关键词出现概率：

| 关键词 | 垃圾邮件 | 普通邮件 |
|---|---|---|
| 免费 | 0.6 | 0.1 |
| 中奖 | 0.5 | 0.05 |

一封新邮件同时含"免费"和"中奖"（关键词相互独立）。判断它是垃圾邮件还是普通邮件。

**【答案】** P(垃圾|D) ∝ 0.18 ≫ P(普通|D) ∝ 0.002 → 判为垃圾邮件。

**【解题步骤】**
1. 设 H₁=垃圾、H₂=普通，D=同时含两个关键词。P(H₁)=0.6、P(H₂)=0.4。
2. 独立性 → P(D|H₁) = 0.6×0.5 = 0.30；P(D|H₂) = 0.1×0.05 = 0.005。
3. 由贝叶斯定理（k=1/P(D) 为公共常数）：
   P(H₁|D) = k×0.30×0.6 = 0.18k；P(H₂|D) = k×0.005×0.4 = 0.002k。
4. 0.18k > 0.002k → **判为垃圾邮件**（约 98.9% 的后验概率：0.18/0.182）。
