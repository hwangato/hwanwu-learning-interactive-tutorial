# 《统计学入门很简单》闪卡（60 张）

> 用法：先遮住"背面"，看"正面"回答。可配合文末说明导入 Anki（另附 `闪卡-anki.tsv`）。

---

## 第 1 章　数据的整理方法

**卡 01**
正面：平均值的计算公式是什么？
背面：x̄ = (x₁+x₂+…+xₙ)/n，即数据总和 ÷ 数据总数。例：178、167、161 的平均 = 168.7。

**卡 02**
正面：中位数怎么求？数据个数为偶数时呢？
背面：数据排序后取正中间的值；偶数个时取中间两个数的平均。

**卡 03**
正面：什么是众数？在直方图上对应什么位置？
背面：出现次数最多的数据；对应直方图的峰顶。

**卡 04**
正面：山型分布和 L 型分布中，平均值、中位数、众数的关系有何不同？
背面：山型分布三者取值接近；L 型分布差别很大（如储蓄分布：众数 < 中位数 < 平均值，平均值被大值拉高）。

**卡 05**
正面：偏差的定义是什么？全部偏差之和等于多少？
背面：偏差 = xᵢ − x̄；全部偏差之和恒等于 0（所以要用平方和来衡量分散程度）。

**卡 06**
正面：波动（偏差平方和）、方差、标准差三者的公式关系？
背面：波动 Q = Σ(xᵢ−x̄)²；方差 = Q/n；标准差 = √方差。标准差的单位与原数据相同。

**卡 07**
正面：方差大小体现了数据的什么性质？方差为 0 意味着什么？
背面：方差大 = 分散程度大 = 数据信息量（个性）丰富；方差为 0 时所有数据相同，统计失去意义。

**卡 08**
正面：协方差 Sxy 的公式？
背面：Sxy = Σ(xᵢ−x̄)(yᵢ−ȳ)/n，即偏差乘积的平均。正相关多时为正，负相关多时为负。

**卡 09**
正面：相关系数 r 的公式和取值范围？
背面：r = Sxy/(Sx·Sy)，取值 −1~1。书中判断标准：|r|≥0.6 强相关，0.2~0.6 普通相关，|r|<0.2 不相关。

**卡 10**
正面：两个定性变量（如血型×性格）的关系用什么表可视化？
背面：交叉表格（列联表）：行列分别为两个变量的取值，格内是同时满足两个条件的个体数。

## 第 2 章　概率 / 总体 / 样本

**卡 11**
正面：概率的古典定义公式？
背面：P(A) = r/n（n 为等可能结果总数，r 为 A 事件包含的结果数）。例：骰子出 ≤2 的概率 = 2/6 = 1/3。

**卡 12**
正面：什么是随机变量？
背面：取值由每次试验的结果决定、且各取值的概率有规律的变量。例：掷硬币正面记 X=1（P=1/2）、反面 X=2（P=1/2）。

**卡 13**
正面：连续随机变量取某个特定值的概率是多少？它的概率如何表示？
背面：取特定值的概率为 0；概率用概率密度函数曲线下的"区间面积"表示，总面积 = 1。

**卡 14**
正面：离散随机变量的期望 E(X) 和方差 V(X) 公式？
背面：E(X) = Σxᵢpᵢ（取值×概率之和）；V(X) = Σ(xᵢ−m)²pᵢ，其中 m=E(X)。

**卡 15**
正面：什么是"上侧 100p 百分点"？什么是"上侧 p 值"？
背面：上侧 100p 百分点：右侧概率为 p 时对应的 x 值（由概率求 x）；上侧 p 值：给定 x 时其右侧的概率（由 x 求概率）。方向相反的一对概念。

**卡 16**
正面：标准化变换的公式？变换后均值和标准差是多少？
背面：z = (x−m)/σ；变换后均值 0、标准差 1。逆变换 x = σz + m。

**卡 17**
正面：样本方差 S² 和无偏方差 s² 的公式区别？哪个具有无偏性？
背面：样本方差分母 n，无偏方差分母 n−1。无偏方差具有无偏性（其平均值 = 总体方差）；样本方差平均偏小。

**卡 18**
正面：为什么无偏方差的分母是 n−1？
背面：因为 n 个偏差受 Σ(Xᵢ−X̄)=0 约束，只有 n−1 个能自由取值，自由度为 n−1。

**卡 19**
正面：什么是自由度？
背面：取值不受限制的变量个数。例：3 个变量若被"平均值=5"约束，自由度为 2。

**卡 20**
正面：正态分布曲线的山顶和山腰（拐点）分别对应什么参数？
背面：山顶横坐标 = 平均值 μ；山腰与 μ 的水平距离 = 标准差 σ。记作 N(μ, σ²)。

**卡 21**
正面：标准正态分布的 4 个常用百分点（上侧5%、两侧5%、上侧1%、两侧1%）分别是多少？
背面：1.65、1.96、2.33、2.58。一般正态对应 μ+1.65σ、μ+1.96σ、μ+2.33σ、μ+2.58σ。

**卡 22**
正面：中心极限定理的内容？
背面：从均值 μ、方差 σ² 的任意总体抽容量 n 的样本：① X̄ 的均值=μ、方差=σ²/n、标准差=σ/√n；② n 足够大（约≥30）时 X̄ 近似正态分布，与总体分布形状无关。

**卡 23**
正面：正态总体的样本均值定理与中心极限定理有何区别？
背面：总体本身是正态 N(μ,σ²) 时，X̄ 对**任意 n** 都严格服从 N(μ, σ²/n)；中心极限定理则不要求总体正态，但要求 n 足够大。

**卡 24**
正面：有放回抽样和不放回抽样，统计学理论上默认哪种？
背面：有放回抽样。总体容量很大时两者实际无差异。

## 第 3 章　估计 / 检验的基本思想

**卡 25**
正面：点估计和区间估计的区别？
背面：点估计给出一个数值（如 μ̂=4 万日元），但正确率无从考证；区间估计给出一个区间并附带置信度（如 95% 置信区间 2.87~5.13）。

**卡 26**
正面：σ 已知时总体均值 μ 的 95% 置信区间公式？
背面：X̄ − 1.96σ/√n ≤ μ ≤ X̄ + 1.96σ/√n。99% 时把 1.96 换成 2.58。

**卡 27**
正面："置信度 95%"的正确含义是什么？
背面：反复抽样得到的所有置信区间中，约 95% 会包含真实的 μ。不能说"μ 有 95% 概率在这个区间的中间"——μ 在区间内的具体位置无人知晓。

**卡 28**
正面：想提高置信度，区间会怎样？想在不降低置信度的情况下缩窄区间，怎么办？
背面：置信度提高 → 区间变宽（1.96→2.58）；想缩窄区间只能增大样本容量 n（分母 √n 变大）。

**卡 29**
正面：统计检验的基本逻辑（三步）？
背面：① 设与主张相反的原假设 H₀；② 假定 H₀ 成立，计算观测结果的概率；③ 概率 < 显著性水平 α → 小概率事件发生了 → 拒绝 H₀、接受备择假设 H₁。

**卡 30**
正面：原假设和备择假设分别是什么？
背面：原假设 H₀：验证者想驳斥的假设（"没有差异/没有变化"）；备择假设 H₁：验证者想证明的主张。

**卡 31**
正面：显著性水平（风险率）α 的含义？
背面：作为"小概率事件"判断基准的概率（常用 0.05、0.01）；同时也是错误拒绝正确原假设的风险。

**卡 32**
正面：什么时候用单侧检验、什么时候用双侧检验？
背面：备择假设"参数>λ"→右侧检验；"参数<λ"→左侧检验；"参数≠λ"→双侧检验（拒绝域两尾各 α/2）。

**卡 33**
正面：第一类错误和第二类错误分别是什么？
背面：第一类（拒真）：H₀ 正确却被拒绝，犯错率=α；第二类：H₀ 错误却没被拒绝，犯错率=β。两者此消彼长。

## 第 4 章　回归 / 方差分析 / 贝叶斯

**卡 34**
正面：一元回归方程的形式？回归线是怎样的直线？
背面：y = ax + b（x 自变量、y 因变量）；是"与所有点距离最小"、即残差平方和最小的直线。

**卡 35**
正面：决定系数 R² 的定义公式？多大算实用？
背面：R² = 预计值的方差 / 测量值的方差（测量值方差 = 预计值方差 + 残差方差）。R² > 0.8 意味着回归方程实际可用。

**卡 36**
正面：为什么需要"自由度调整后的决定系数 R̄²"？公式是什么？
背面：因为乱加自变量 R² 也会虚增。R̄² = 1 − (n−1)(1−R²)/(n−k−1)（n 数据数、k 自变量数），加入无关变量时 R̄² 会下降。

**卡 37**
正面：方差分析的基本思想是什么？
背面：比较"组间变异"与"组内变异（偶然误差）"：组间变异远大于组内变异时，认为组间差异不是偶然，效果存在差异。

**卡 38**
正面：单因素方差分析中 F 统计量怎么构造？服从什么分布？
背面：F = s₁²/s₂² = (Q₁/f₁)/(Q₂/f₂)，组间无偏方差÷组内无偏方差；H₀ 成立时服从 F(f₁, f₂)。f₁=组数−1，f₂=(区块数−1)×组数。

**卡 39**
正面：方差分析中"原始数据"可以分解成哪三部分？波动如何分解？
背面：原始数据 = 总体均值 + 组间偏差 + 组内偏差；总波动 Q = 组间波动 Q₁ + 组内波动 Q₂。

**卡 40**
正面：方差分析术语：因素、水平分别指什么？"有反复"是什么意思？
背面：因素（因子）＝影响结果的要素（如肥料）；水平＝因素的不同取值（如肥料 A/B/C）；同一条件组合下有多个数据称"有反复"，只有一个称"无反复"。

**卡 41**
正面：双因素（有反复）方差分析比无反复多分析了什么？
背面：相互作用（交互效应）。相互作用偏差 = 原始数据 − 总体均值 − 因素1组间偏差 − 因素2组间偏差 − 组内偏差；自由度 = (水平数1−1)×(水平数2−1)。

**卡 42**
正面：加法定理和乘法定理的公式？
背面：加法定理（互斥）：P(A或B) = P(A)+P(B)；乘法定理：P(A且B) = P(A)×P(B|A)。

**卡 43**
正面：条件概率 P(B|A) 的含义？
背面：把 A 看作新的样本空间时 B 发生的概率。例：已知抽中红心，是画像的概率 = 3/13（红心 13 张中画像 3 张）。

**卡 44**
正面：贝叶斯定理的公式？各项名称？
背面：P(H|D) = P(D|H)·P(H)/P(D)。P(H) 先验概率、P(H|D) 后验概率、P(D|H) 似然度。

**卡 45**
正面：什么是"不充分理由原则（不充分理由效应）"？
背面：没有任何信息时，把所有可能情况的先验概率设为相等（如 4 种口袋组合各 1/4、θ 均匀分布）。

## 第 5～6 章　应用

**卡 46**
正面：三项移动平均的计算方法和作用？
背面：X'₂=(X₁+X₂+X₃)/3、X'₃=(X₂+X₃+X₄)/3……用前后相邻项平均替代原值，平滑短期波动、显现长期趋势。

**卡 47**
正面：发现异常值最有效的可视化手段是什么？处理原则？
背面：相关图（散点图）一眼可见离群点；查明原因后剔除再分析，防止异常值扭曲结论（书例：剔除 1 个异常值后"数学差于英语"反转为"数学好于英语"）。

**卡 48**
正面：期望值的两种等价算法？
背面：① Σ(各金额×其概率)；② 奖金总额÷奖券总数。本质是平均值。例：奖券期望 30 日元 < 票价 50 日元 → 不该参加。

**卡 49**
正面：蒙特卡罗法求 π 的公式？
背面：2m 正方形内切 1m 圆，随机撒点：正方形 m 粒、圆内 n 粒 → 4:π ≈ m:n → π ≈ 4n/m。

**卡 50**
正面：大数定律的内容？
背面：随试验次数增加，事件的相对频率趋近其真实概率；试验初期频率会"摇摆不定"（书中用它解释短期的幸运与不幸）。

**卡 51**
正面：问卷调查需要多少样本？误差公式是什么？
背面：95% 置信下 R ∈ r±e，e = 2√(r(1−r)/n)。r=0.5 时 e 最大；n=400 时 e≈0.05 已够，n=1000 万无一失；所需样本量与总体规模无关。

## 第 7 章　估计 / 检验的应用

**卡 52**
正面：极大似然估计法的思想？
背面：把观测结果的概率写成参数的函数（似然函数），取使它最大的参数值作为估计值。例：图钉 5 次"上上下上下"→ y=p³(1−p)² → p̂=0.6。

**卡 53**
正面：估计总体均值时，"大样本 / 小样本正态总体σ未知 / σ已知"三种情形各用什么？
背面：大样本(n≥30)：X̄±1.96·s/√n（中心极限定理，σ≈s）；小样本：t 分布，X̄±t(n−1)·s/√n；σ 已知的正态总体：X̄±1.96·σ/√n。

**卡 54**
正面：t 统计量的公式？服从什么分布？
背面：T = (X̄−μ)/(s/√n)，服从自由度 n−1 的 t 分布（n≥30 时近似标准正态）。

**卡 55**
正面：样本比例 r 的分布？总体比例的 95% 置信区间？
背面：r ~ N(R, R(1−R)/n)；置信区间 r ± 1.96√(r(1−r)/n)。推导要点：0-1 变量的 μ=R、σ²=R(1−R)。

**卡 56**
正面：总体方差的区间估计用什么统计量、什么分布？
背面：K = (n−1)s²/σ² ~ χ²(n−1)；由 χ²下限 ≤ K ≤ χ²上限 变形得 (n−1)s²/χ²上限 ≤ σ² ≤ (n−1)s²/χ²下限。

**卡 57**
正面：两独立样本均值差检验（方差相同未知）的 T 统计量和自由度？
背面：T = (X̄A−X̄B) / √[ (1/nA+1/nB) · ((nA−1)sA²+(nB−1)sB²)/(nA+nB−2) ]，自由度 nA+nB−2。

**卡 58**
正面：两总体比例差检验的 z 统计量？
背面：z = (p₁−p₂)/√[ p(1−p)(1/n₁+1/n₂) ]，其中合并比例 p = (n₁p₁+n₂p₂)/(n₁+n₂)；H₀ 成立时 z ~ N(0,1)。

**卡 59**
正面：χ² 拟合优度检验和独立性检验的统计量与自由度？
背面：χ² = Σ(观测−期望)²/期望。拟合优度 df=类别数−1；列联表独立性检验期望频率=行合计×列合计÷总数，df=(行数−1)×(列数−1)。均用上侧检验。

**卡 60**
正面：贝叶斯更新（硬币 θ）：均匀先验下第 1 次掷出正面后，θ 的后验分布是什么？体现了什么思想？
背面：P(θ|正面)=2θ（连续两正面→3θ²；再反面→12θ²(1−θ)，峰值 θ=2/3）。体现"概率随经验数据不断更新"，且与数据顺序无关（顺序合理性）。

## 导入 Anki 的方法
1. 用同目录的 `闪卡-anki.tsv`（制表符分隔，两列：正面、背面）。
2. Anki → 文件 → 导入，选择该文件，字段分隔符选"Tab"，将两列分别映射到"正面/背面"即可。
